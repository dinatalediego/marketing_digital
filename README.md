# Marketing Digital Lab — de pauta a ventas

Este repositorio es una ruta práctica para aprender a invertir en anuncios de Instagram y Facebook con criterio de negocio.

El caso de entrenamiento principal es **LimpiaFast / Expertos en Lavados**: un servicio local donde la pauta debe producir conversaciones útiles en WhatsApp, cotizaciones y finalmente reservas rentables.

> La pauta no compra ventas. Compra oportunidades de atención. El sistema completo convierte esas oportunidades en ventas.

## Objetivo

Llegar al punto en que puedas responder, con datos:

1. ¿Qué necesidad estoy vendiendo realmente?
2. ¿Qué anuncio merece presupuesto mañana?
3. ¿Qué anuncio debo apagar?
4. ¿Cuánto puedo pagar por una conversación, cotización y reserva?
5. ¿El problema está en el anuncio, la audiencia, WhatsApp, el precio o el seguimiento?
6. ¿Qué experimento ejecuto después?

## Cómo estudiar este repositorio

No avances por cantidad de páginas leídas. Avanza por **evidencia producida**.

Para cada módulo:

- entender el concepto;
- aplicarlo a Expertos en Lavados;
- crear una hipótesis;
- ejecutar o simular una prueba;
- registrar el resultado;
- escribir qué decisión tomarías.

Usa las plantillas:

- [`ad_brief.md`](templates/ad_brief.md)
- [`experiment_card.md`](templates/experiment_card.md)

## Caso conectado: Expertos en Lavados

Repositorio operativo:

https://github.com/dinatalediego/expertos_en_lavados

Allí el funnel definido es:

**anuncio → conversación inmediata → calificación → cotización → reserva → servicio → recompra/referido**.

Este repositorio explica **cómo pensar y aprender a manejar la inversión** que alimenta ese funnel.

## El tablero mental que debes aprender

| Capa | Pregunta | Métrica que importa |
|---|---|---|
| Atención | ¿Detuve el scroll correcto? | CPM, hook/video, CTR como diagnóstico |
| Intención | ¿La persona quiso saber más? | clic / conversación iniciada |
| Calificación | ¿Era un posible cliente real? | % conversación → lead calificado |
| Oferta | ¿Entendió valor y precio? | % calificado → cotización |
| Venta | ¿Reservó? | % cotización → reserva |
| Economía | ¿Ganamos dinero? | CAC por reserva, margen después de pauta |
| Aprendizaje | ¿Qué sabemos ahora que ayer no? | experimentos concluyentes |

CTR, likes y seguidores pueden ayudar a diagnosticar. **No son el objetivo económico.**

## Principio central para un servicio local

Meta puede encontrar personas; tu negocio debe imponer restricciones que la plataforma no conoce:

- zonas donde realmente atiendes;
- capacidad diaria;
- ticket y margen por tipo de servicio;
- horarios;
- tiempo de respuesta;
- criterios mínimos para considerar un lead útil.

Dentro de esas restricciones, evita microsegmentar por intuición sin evidencia. Empieza simple, deja espacio al sistema de entrega y aprende con tus propios datos.
