# 06 — Medición: del anuncio al margen

La medición debe permitir ubicar dónde se rompe el sistema.

## Funnel mínimo

1. impresiones
2. clics / conversaciones iniciadas
3. leads calificados
4. cotizaciones
5. reservas
6. servicios realizados
7. recompras / referidos

## KPIs principales

- **Costo por conversación** = pauta / conversaciones
- **Costo por lead calificado** = pauta / leads calificados
- **Costo por cotización** = pauta / cotizaciones
- **CAC por reserva** = pauta / reservas
- **Conversión conversación → reserva** = reservas / conversaciones
- **Ticket promedio** = ventas / reservas
- **Margen después de pauta** = margen antes de pauta - inversión atribuida

## Diagnóstico por capa

| Señal | Lectura posible |
|---|---|
| CPM alto | competencia, audiencia, calidad/entrega |
| CTR bajo | hook/mensaje poco relevante |
| CTR alto + pocos chats | fricción de destino o intención débil |
| muchos chats + pocos calificados | creativo/promesa atrae curiosidad |
| muchos calificados + pocas cotizaciones | operación lenta o datos incompletos |
| muchas cotizaciones + pocas reservas | precio, confianza, disponibilidad, seguimiento |
| CAC bueno + poca capacidad | problema operacional, no de publicidad |

Nunca diagnostiques con una sola métrica.

## Unidad correcta de decisión

Siempre que sea posible analiza por:

**campaña + conjunto + anuncio + concepto creativo + fecha + servicio + zona**

Luego conecta cada lead y reserva con esos identificadores.

## Preguntas para el cierre semanal

1. ¿Cuánto invertimos?
2. ¿Cuántas reservas atribuibles obtuvimos?
3. ¿Cuál fue el CAC?
4. ¿Qué concepto creativo tuvo mejor CAC, no solo CTR?
5. ¿Dónde estuvo la mayor fuga?
6. ¿Qué parte es responsabilidad de Ads y qué parte de ventas/operación?
7. ¿Qué decisión concreta cambia la próxima semana?

## North Star

Para Expertos en Lavados:

**reservas rentables generadas por pauta**

La plataforma puede reportar eventos propios; conserva además un registro de negocio que permita auditar qué lead terminó realmente en servicio pagado.
